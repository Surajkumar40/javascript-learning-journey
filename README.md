# JavaScript Learning Journey

A structured, hands-on collection of JavaScript concepts, from core fundamentals
to object-oriented programming, with practical mini projects along the way.

## Topics Covered

| Folder | What's Inside |
|---|---|
| `01_basics` – `03_basics` | Variables, data types, operators, functions, arrays, objects |
| `04_control_flow` | if/else, switch, ternary operator, logical flow |
| `05_iterations` | for, while, do-while, for...of, for...in, array methods |
| `06_dom` | Selecting, creating, and modifying DOM elements |
| `07_projects` | Mini projects applying the concepts above |
| `08_events` | Event listeners, bubbling, event delegation |
| `09_advance` | Closures, promises, async/await, ES6+ features |
| `10_classes_and_oop` | Classes, inheritance, encapsulation, polymorphism |

## Projects

| Project | Description | Concepts Used |
|---|---|---|
| **Color Change Background** | Changes the page background color on button click | DOM selection, event listeners |
| **BMI Calculator** | Calculates Body Mass Index from height and weight and shows the result category | DOM, input handling, conditionals |
| **Clock** | Live digital clock that updates every second | `Date` object, `setInterval` |
| **Guess the Number** | Game where the user guesses a random number with hints | Math.random, loops, conditionals |

## How to Run

1. Clone the repo:
```bash
   git clone https://github.com/Surajkumar40/javascript-learning-journey.git
```
2. Open the folder in VS Code.
3. For plain JS files, run `node filename.js`.
4. For projects, open the `index.html` file in your browser.
